# 🛒 Blinkit Retail & Grocery Analytics Dashboard | Power BI

## 📌 Project Overview

The Blinkit Retail & Grocery Analytics Dashboard is an interactive Power BI project designed to analyze grocery sales performance, product categories, outlet characteristics, customer ratings, and outlet-level trends.

The dashboard transforms retail data into visual reports that help users explore sales performance and compare products and outlets across different business dimensions.

## 🎯 Project Objectives

- Analyze overall sales and key performance indicators.
- Compare sales across item types and outlet types.
- Examine sales performance across outlet tiers.
- Explore fat-content distribution and product characteristics.
- Analyze outlet establishment and sales trends over time.
- Compare customer ratings and product performance.
- Build an interactive dashboard for business reporting.

## 🛠️ Tools & Technologies

- **Business Intelligence:** Microsoft Power BI
- **Data Transformation:** Power Query
- **Calculations:** DAX
- **Data Modeling:** Relationships and measures
- **Visualization:** Charts, KPI cards, slicers, tables, and other Power BI visuals

## 📊 Key Performance Indicators

The dashboard includes analysis of metrics such as:

- **Total Sales:** Overall sales value represented in the dataset.
- **Sales per Outlet:** Average sales per outlet, when calculated using the intended outlet-level definition.
- **Average Rating:** Average customer rating where available.
- **Number of Items:** Count of items or records, depending on the measure definition.
- **Outlet Performance:** Comparison of sales across outlet types and tiers.

The dashboard reports approximately **$1.20 million in sales**, based on the project figures previously shared.

## 📈 Dashboard Analysis

### 1. Sales Performance
Analyze total sales and compare sales contributions across item types, outlet types, and outlet tiers.

### 2. Product Analysis
Explore sales by item type and fat content to understand differences across grocery product categories.

### 3. Outlet Analysis
Compare outlet performance by outlet type, tier, and establishment period.

### 4. Customer Ratings
Review customer ratings and examine how ratings vary across products and outlet characteristics.

### 5. Interactive Exploration
Use slicers and report navigation to filter the data and compare business performance across different categories.

## 🔄 Project Workflow

1. Import retail data into Power BI.
2. Inspect and clean the dataset using Power Query.
3. Prepare the data model and relationships where required.
4. Create DAX measures for KPIs and sales analysis.
5. Build charts, cards, tables, and interactive filters.
6. Validate calculations and review the findings.
7. Present the results in an interactive dashboard.

## 💡 Business Value

- Helps compare sales performance across outlets.
- Highlights product categories contributing to sales.
- Supports exploration of outlet-tier differences.
- Makes retail KPIs easier to monitor.
- Provides a foundation for further analysis of product and outlet performance.

## 🚀 How to Explore the Dashboard

1. Download the `.pbix` file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. Wait for the report to load.
4. Explore the charts and use the available slicers to filter the report.
